## 1. Mathematical Standards for Quantum Kernel Matrices

For a statevector fidelity quantum kernel matrix $K \in \mathbb{R}^{N \times N}$ generated by $K_{ij} = |\langle \psi(\mathbf{x}_i) \mid \psi(\mathbf{x}_j) \rangle|^2$ to serve as a valid Mercer kernel for convex Support Vector Classification, it must satisfy:

1. **Exact Symmetry:** $K = K^T \iff \max_{i, j} |K_{ij} - K_{ji}| = 0$.
2. **Normalized Self-Fidelity:** $K_{ii} = |\langle \psi(\mathbf{x}_i) \mid \psi(\mathbf{x}_i) \rangle|^2 = 1.0 \iff \max_i |K_{ii} - 1.0| = 0$.
3. **Finiteness:** $|K_{ij}| < \infty$ for all $i, j$ (no `NaN`, `Inf`, or complex residuals).
4. **Bounded State Overlap:** $0.0 \le K_{ij} \le 1.0$ for all $i, j$.
5. **Positive Semi-Definiteness (PSD):** $\mathbf{v}^T K \mathbf{v} \ge 0$ for all $\mathbf{v} \in \mathbb{R}^N \iff \lambda_{\min}(K) \ge 0.0$.
6. **Exact Trace:** $\text{Tr}(K) = \sum_{i=1}^N K_{ii} = N$.
